概述

桃桃记账是一款本地优先的记账工具，默认将你的数据保存在本机。以下说明你的数据如何被使用、存储与删除。

  • 账本、明细、账户、预算、备注和照片附件默认仅保存在本机。
  • 照片附件与备份默认仅保存在本机；Android 本地备份写入主存储 Documents/桃桃记账，Android 10 及以上无需存储权限，Android 9 及以下会申请存储写入权限；iOS 备份仍保存在 App 本机沙盒，卸载即失。
  • 微信登录为可选，仅用于会员权益，本地记账无需登录；默认不会上传你的账本数据，也无广告追踪。会员可主动开启加密云备份，把账本备份加密后存到腾讯云（见「可选会员云备份」）。
  • 你同意隐私政策后，App 会自动更新检查；仅发送平台、App 版本、Build、随机安装实例 ID、机型、厂商、品牌、系统版本、Android API 级别和 locale，不读取硬件 ID，更新检查本身不涉及账本内容。

基本说明

桃桃记账是一款本地优先的记账工具。本地记账无需登录，默认也不会主动将你的账本数据上传到开发者服务器。仅当你主动开启会员云备份时，App 才会在本机把账本备份加密为 .taocb 密文并直传腾讯云对象存储（详见「可选会员云备份」）。微信登录为可选，仅用于会员权益绑定。

可选微信登录

微信登录完全可选，仅用于会员权益。登录后服务端只保存微信昵称、头像 URL、openid/unionid、桃桃业务登录态和会员权益状态，不接收账本、明细、账户、预算、AA 账单或照片附件的明文。会员云备份的加密正文直传腾讯云对象存储 COS，不经过家庭服务器，详见「可选会员云备份」。

可选会员云备份

云备份是会员可选功能，默认关闭，不会在你不知情时自动开启，也不是多端实时同步或多设备合并。开启后，App 会在本机用 AES-256-GCM 算法把账本备份 ZIP 加密为 .taocb 密文，再通过 HTTPS 直传腾讯云对象存储 COS（北京地域）的私有桶；备份正文不经过家庭服务器，家庭服务器只保存你的账号、备份元数据，以及由独立主密钥加密包装的每用户托管密钥。每用户最多保留 5 份加密备份；关闭云备份开关、退出登录或会员到期都不会自动删除已上传的加密备份，你可以在「隐私与协议」中手动删除全部云端备份。需要说明的是：每用户密钥由家庭服务器用独立主密钥加密托管，服务端在授权请求中能够解封该密钥并校验备份；只要你开启并使用云备份，加密账本密文就会上传到腾讯云 COS，因此本功能并非服务端完全无法访问的托管方式，开启后账本数据的加密备份也会存在于腾讯云。

我们如何使用数据

你录入的账本、明细、账户、预算、备注、图片附件、AA 账单和小票，用于在本机展示记账、统计、预算、资产和备份恢复。你主动提交意见反馈时，反馈文字、联系方式、你选择或截屏带入的图片，以及非敏感诊断设备信息会发送到桃桃服务端，用于问题排查和回复。诊断设备信息包括机型、厂商、品牌、系统版本、语言地区、Android 设备代号、Android API 级别、安全补丁、CPU ABI、屏幕尺寸、像素比、CPU 核心数，以及有限的调试环境状态（USB 调试、不保留活动、显示触摸操作、动画缩放）。

App 更新检查

你同意隐私政策后，为判断当前版本兼容性、灰度范围和是否需要提示或强制更新，App 会自动更新检查。检查只发送平台、App 版本、Build、随机安装实例 ID、机型、厂商、品牌、系统版本、Android API 级别和 locale；不读取 Android ID、广告 ID、设备序列号、MAC 地址等硬件 ID，更新检查本身不涉及账本内容。随机安装实例 ID 由 App 本地生成，仅用于稳定灰度、去重和更新事件统计。

不会主动收集

手机号、邮箱、真实姓名、身份证号、精确位置、通讯录、短信、通话记录、广告 ID、Android ID、设备序列号、MAC 地址、WiFi/蓝牙列表、未列入意见反馈诊断白名单的开发者选项状态、已安装应用列表和用于广告画像的数据。

意见反馈诊断信息

为帮助判断机型、系统版本、屏幕适配、CPU 架构和调试环境相关问题，用户主动提交意见反馈时会附带非敏感诊断设备信息。调试环境仅包括 USB 调试、不保留活动、显示触摸操作和动画缩放；不包含指针位置、保持唤醒、Android ID、MAC 地址、设备序列号、定位、通讯录、应用列表或 WiFi/蓝牙列表。

数据流向

备份在 Android 上写入主存储的 Documents/桃桃记账公共目录，在 iOS 上写入 App 本机沙盒（不主动外传、随整机备份保留、卸载即失）。使用截屏反馈、系统分享、保存到相册、导出备份、导入恢复时，数据会交由你选择的反馈服务、系统服务、目录或目标 App 处理。开启会员云备份后，账本备份会在本机用 AES-256-GCM 加密为密文，再通过 HTTPS 直传腾讯云对象存储 COS（北京地域）的私有桶，备份正文不经过家庭服务器。

删除与撤回

你可以删除明细、账本、账户、AA 账单和备份文件，也可以撤回隐私同意。撤回隐私同意时，App 会清除本机业务数据库、照片附件、备份临时文件、隐私同意记录和权限告知确认记录，并在完成后关闭。已经导出或分享到外部目录、相册、其他 App 的文件不会自动删除。撤回只会清除本机数据，不会自动删除你已上传到腾讯云的加密备份；如需删除，请在「隐私与协议」中使用「删除全部云备份」入口，且需在登录状态下才能完成远端删除。

儿童与未成年人

桃桃记账不是专门面向儿童的产品。未成年人应在监护人同意和指导下使用。

数据出境与第三方共享

桃桃记账默认不会主动向开发者服务器上传用户账本数据。可选的微信登录会把微信昵称、头像 URL、openid/unionid 和业务登录态发送给桃桃服务端（境内），用于会员权益绑定，但不包含任何账本数据。会员云备份的加密密文存储在腾讯云对象存储 COS 北京地域（境内），不传输到境外服务器；家庭服务器只保存账号、备份元数据和加密托管密钥，不接收备份正文。
