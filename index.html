概述

桃桃记账是一款本地优先的记账工具，默认将你的数据保存在本机。以下说明你的数据如何被使用、存储与删除。

  • 账本、明细、账户、预算、备注和照片附件默认仅保存在本机。
  • 照片附件与备份默认仅保存在本机；iOS 上的自动备份会在本机留存一份，不主动外传，卸载即失。主动添加照片、保存小票、外置备份、导入恢复和系统分享只在你操作时调用。
  • 微信登录为可选，仅用于会员权益，本地记账无需登录；不做云同步、无广告追踪，也不上传你的账本数据。
  • 你同意隐私政策后，App 会自动更新检查；仅发送平台、App 版本、Build、随机安装实例 ID、机型、厂商、品牌、系统版本、Android API 级别和 locale，不读取硬件 ID，也不上传账本数据。

基本说明

桃桃记账是一款本地优先的记账工具。本地记账无需登录，也不会主动将你的账本数据上传到开发者服务器。微信登录为可选，仅用于会员权益绑定。

可选微信登录

微信登录完全可选，仅用于会员权益。登录后服务端只保存微信昵称、头像 URL、openid/unionid、桃桃业务登录态和会员权益状态，仍不上传账本、明细、账户、预算、AA 账单或照片附件。

我们如何使用数据

你录入的账本、明细、账户、预算、备注、图片附件、AA 账单和小票，用于在本机展示记账、统计、预算、资产和备份恢复。你主动提交意见反馈时，反馈文字、联系方式、你选择或截屏带入的图片，以及非敏感诊断设备信息会发送到桃桃服务端，用于问题排查和回复。诊断设备信息包括机型、厂商、品牌、系统版本、语言地区、Android 设备代号、Android API 级别、安全补丁、CPU ABI、屏幕尺寸、像素比、CPU 核心数，以及有限的调试环境状态（USB 调试、不保留活动、显示触摸操作、动画缩放）。

App 更新检查

你同意隐私政策后，为判断当前版本兼容性、灰度范围和是否需要提示或强制更新，App 会自动更新检查。检查只发送平台、App 版本、Build、随机安装实例 ID、机型、厂商、品牌、系统版本、Android API 级别和 locale；不读取 Android ID、广告 ID、设备序列号、MAC 地址等硬件 ID，也不上传账本数据。随机安装实例 ID 由 App 本地生成，仅用于稳定灰度、去重和更新事件统计。

不会主动收集

手机号、邮箱、真实姓名、身份证号、精确位置、通讯录、短信、通话记录、广告 ID、Android ID、设备序列号、MAC 地址、WiFi/蓝牙列表、未列入意见反馈诊断白名单的开发者选项状态、已安装应用列表和用于广告画像的数据。

意见反馈诊断信息

为帮助判断机型、系统版本、屏幕适配、CPU 架构和调试环境相关问题，用户主动提交意见反馈时会附带非敏感诊断设备信息。调试环境仅包括 USB 调试、不保留活动、显示触摸操作和动画缩放；不包含指针位置、保持唤醒、Android ID、MAC 地址、设备序列号、定位、通讯录、应用列表或 WiFi/蓝牙列表。

数据流向

备份在 Android 上写入你授权的外置目录，在 iOS 上写入 App 本机沙盒（不主动外传、随整机备份保留、卸载即失）。使用截屏反馈、系统分享、保存到相册、导出备份、导入恢复时，数据会交由你选择的反馈服务、系统服务、目录或目标 App 处理。

删除与撤回

你可以删除明细、账本、账户、AA 账单和备份文件，也可以撤回隐私同意。撤回隐私同意时，App 会清除本机业务数据库、照片附件、备份临时文件、隐私同意记录和权限告知确认记录，并在完成后关闭。已经导出或分享到外部目录、相册、其他 App 的文件不会自动删除。

儿童与未成年人

桃桃记账不是专门面向儿童的产品。未成年人应在监护人同意和指导下使用。

数据出境与第三方共享

桃桃记账不会主动向开发者服务器上传用户账本数据，也不会主动向境外服务器传输用户账本数据。可选的微信登录会把微信昵称、头像 URL、openid/unionid 和业务登录态发送给桃桃服务端，用于会员权益绑定，但不包含任何账本数据。
